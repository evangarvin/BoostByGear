# Fonts

Both fonts used by the app are bundled here, fully open-source and safe to
redistribute — no extra downloads needed to run the app.

| File | Used for | License |
|---|---|---|
| `StackSansText-Bold.ttf` | Body text, labels | [SIL Open Font License 1.1](OFL-StackSans.txt) |
| `Manrope-Bold.ttf` | The big gear-number readout | [SIL Open Font License 1.1](OFL-Manrope.txt) |

Both licenses permit bundling with software as long as the copyright
notice and license text travel with the font — that's what the two
`OFL-*.txt` files here are for.
